# Дефект или норма

Скрипт принимает путь к картинке и печатает `OK` или `DEFECT`.

## Требования

- **Python 3.8 или новее** (проверено на Python 3.12.3)
- Библиотека **Pillow 10.0+** (проверено на Pillow 12.1.1)

Проверить версию Python: `python --version`

## Запуск

```bash
pip install -r requirements.txt
python defect_check.py ok.png       # -> OK
python defect_check.py defect.png   # -> DEFECT
```

Если нужно пересоздать тестовые картинки: `python make_samples.py`.

## Как работает

Модели нет, правило простое: картинка уменьшается до 256×256, затем
считается доля «красных» пикселей (R > 150, G < 100, B < 100).
Если красного **≥ 2%** кадра — `DEFECT`, иначе `OK`.

| файл       | доля красного | результат |
|------------|---------------|-----------|
| ok.png     | 0%            | OK        |
| defect.png | ~3.7%         | DEFECT    |

Коды выхода: `0` — успех, `1` — файл не открылся, `2` — не передан аргумент.

## Что получилось и ограничения

- Работает на тестовых примерах, зависимостей минимум (только Pillow).
- Реальный красный предмет в кадре (например, красный фон) будет ложно
  считаться браком — правило смотрит только на цвет, а не на форму.
- Следующий шаг: вместо цвета обучить небольшую модель (классификатор
  или поиск аномалий) на реальных фото деталей.
